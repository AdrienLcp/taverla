# Stage 27 — The host's remote

Asked while trying the slate: run the room from **my phone**, and let the
computer's screen show only what the room should see.

## The idea

Today the host is one screen that both controls and displays — which is why the
slate hides its key behind a fold and why judging happens in front of everyone.
Split the role: a **wall** (display only: QR code, progress, the item being
marked, scores) and a **remote** (controls, the key, the answers before they are
shown), both holding the room's host token.

## Why it is its own stage

It is the shell's, not a game's: every game gains from it (a blind-test host
judging from the sofa, a quiz host reading the answer privately). It touches the
host claim and token, the second-console rules (`second-console.test.ts`), and
every console screen. Read `docs/game-catalogue.md` and stage 11's divergences
before scoping it. Not started; needs its own plan session.
